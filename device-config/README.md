# Конфигурация главного экрана (VONTAR X4)

`flauncher-layout.json` — экспорт раскладки категорий главного экрана с
TV-приставки **VONTAR X4** (`DPI63a0MIDLE0000`, Android 11, кастомная сборка
FLauncher `0.18.0-tvbox`).

## Состав

| # | Категория | Тип | Приложений |
|--:|---|---|---:|
| 0 | Избранное | строка | 5 |
| 1 | Кино и сериалы | сетка | 8 |
| 2 | Интернет и соцсети | сетка | 5 |
| 3 | Утилиты и настройки | сетка | 18 |
| | **Итого** | | **36** |

Избранное (верхняя строка): SmartTube, Anixart, Кинопоиск, NUM, «Все
приложения» (App Drawer).

## Исключённые пакеты

Из этого экспорта по решению владельца вырезаны **три приложения** — их
названия здесь не публикуются (в таблице выше их нет: 36 вместо 39).

На самой приставке эти приложения сохранены и остаются в категории
«Утилиты и настройки» — вырезаны только из этой публикации.

## Как применить раскладку вручную

1. Откройте настройки FLauncher (⚙ на главном экране).
2. «Категории» → «+» → имя категории, тип **строка** (row) или **сетка**
   (grid), порядок — как в JSON (`order`).
3. Внутри категории «Приложения» → добавьте нужные, порядок — по полю
   `order` в JSON.
4. Названия приложений в JSON (`label`) — справочные, ориентироваться на
   пакет (`package`).

Альтернатива для своих устройств: раскладка хранится в SQLite
(`/data/data/me.efesser.flauncher/app_flutter/db.sqlite`, таблицы
`categories` и `apps_categories`) — правится скриптом со стороны ADB+root.
